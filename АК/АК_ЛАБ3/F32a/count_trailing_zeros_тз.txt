	def count_trailing_zeros(n):
    """Count the number of trailing zeros in the binary representation of an integer.

    Args:
        n (int): The integer to count trailing zeros for.

    Returns:
        int: The number of trailing zeros.
    """
    if n == 0:
        return 32
    count = 0
    while (n & 1) == 0:
        count += 1
        n >>= 1
    return count


assert count_trailing_zeros(1) == 0
assert count_trailing_zeros(2) == 1
assert count_trailing_zeros(16) == 4


Подсчитывает количество нулей в конце двоичного представления целого числа.
Аргументы: n (int) — целое число, для которого нужно посчитать хвостовые нули.
Возвращает: int — количество нулей в конце.

Функция делает цикл:
	1	Смотрит на последний бит
	◦	если он 0 → это хвостовой ноль
	◦	если 1 → дальше считать не нужно
	2	Если бит = 0:
	◦	увеличивает счётчик
	◦	сдвигает число вправо (n >>= 1) → как будто “убирает” этот ноль
	3	Повторяет, пока не встретит 1
Функция идёт справа налево по битам числа и считает нули, пока не встретит первую единицу.
