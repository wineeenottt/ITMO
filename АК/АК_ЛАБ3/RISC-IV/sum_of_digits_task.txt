risc-iv-32: использовать вложенных процедур1, с целью демонстрации работы со стеком. Где применимо -- рекомендуется рекурсивное решение задачи.

(1 - Одна процедура вызывает другую процедуру.)

def sum_of_digits(n):
    """Calculate the sum of the digits of a number"""
    total = 0
    n = abs(n)
    while n > 0:
        total += n % 10
        n //= 10
    return total


assert sum_of_digits(123) == 6
assert sum_of_digits(-456) == 15

Функция считает сумму цифр числа.
abs(n) → берём модуль числа(если число отрицательное, делаем его положительным)
Цикл while n > 0:
	•	n % 10 → берём последнюю цифру
	•	добавляем её в total
	•	n //= 10 → убираем последнюю цифру
