# RISC-IV ISA (с пояснениями)

## Архитектура
RISC-IV — 32-битная RISC-архитектура, похожая на RISC-V.

Основные особенности:
- 32 регистра общего назначения
- Zero-регистр всегда = 0 (запись игнорируется)
- все инструкции = 4 байта
- модель load-store (память только через lw/sw/lb/sb)
- простые инструкции и прямой контроль выполнения
- поддержка вызовов функций (jal/jr)

## 📌 Директивы (работа с адресами)

%hi(symbol)
→ берёт старшие 20 бит адреса

%lo(symbol)
→ берёт младшие 12 бит адреса

💡 Используются вместе для загрузки полного 32-битного адреса:

lui a0, %hi(address)
addi a0, a0, %lo(address)

---

## 📥 Инструкции передачи данных

lui rd, k
→ загружает число в верхние 20 бит
rd = (k & 0x000FFFFF) << 12

mv rd, rs
→ копирует значение регистра
rd = rs

sw rs2, offset(rs1)
→ записывает слово в память
M[rs1 + offset] = rs2

sb rs2, offset(rs1)
→ записывает 1 байт (8 бит)
M[rs1 + offset] = rs2 & 0xFF

lw rd, offset(rs1)
→ загружает слово из памяти
rd = M[rs1 + offset]

lb rd, offset(rs1)
→ загружает байт и расширяет знак
rd = sign-extend(M[rs1 + offset])

---

## ➕ Арифметика

addi rd, rs1, k
→ сложение с числом
rd = rs1 + k (с учётом знака)

slti rd, rs1, k
→ сравнение < числа
rd = 1 если rs1 < k иначе 0

add rd, rs1, rs2
→ сложение регистров
rd = rs1 + rs2

sub rd, rs1, rs2
→ вычитание
rd = rs1 - rs2

mul rd, rs1, rs2
→ умножение
rd = rs1 * rs2

mulh rd, rs1, rs2
→ старшая часть результата умножения

div rd, rs1, rs2
→ деление
rd = rs1 / rs2

rem rd, rs1, rs2
→ остаток от деления
rd = rs1 % rs2

---

## 🔧 Битовые операции

slli rd, rs1, k
→ сдвиг влево

srli rd, rs1, k
→ логический сдвиг вправо (заполняется 0)

srai rd, rs1, k
→ арифметический сдвиг вправо (с сохранением знака)

sll / srl / sra
→ сдвиг по значению регистра rs2

and rd = rs1 & rs2
→ побитовое И

or rd = rs1 | rs2
→ побитовое ИЛИ

xor rd = rs1 ^ rs2
→ побитовое исключающее ИЛИ

andi / ori / xori
→ то же самое, но с числом

---

## 🔁 Управление потоком

j k
→ безусловный переход
pc = pc + k

jal rd, k
→ вызов функции
rd = pc + 4 (адрес возврата)
pc = pc + k

jr rs
→ переход по адресу в регистре
pc = rs

---

## 🟢 Условия (ветвления)

beqz rs, k
→ если rs == 0 → переход

bnez rs, k
→ если rs != 0 → переход

beq rs1, rs2, k
→ если равны

bne rs1, rs2, k
→ если не равны

bgt rs1, rs2, k
→ если rs1 > rs2

ble rs1, rs2, k
→ если rs1 <= rs2

bgtu / bleu
→ то же самое, но без знака (unsigned)

## 🛑 Остановка

halt
→ завершение программы

## 📦 Регистры

Zero  → всегда 0  
Ra    → адрес возврата  
Sp    → стек  
Gp    → глобальные данные  
Tp    → thread pointer  

T0–T6 → временные регистры  
S0–S11 → сохраняемые регистры  
A0–A7 → аргументы функций
